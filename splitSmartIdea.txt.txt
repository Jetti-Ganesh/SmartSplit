# SplitSmart - Complete Project Documentation

## 📱 APP STRUCTURE & NAVIGATION

### **Page Hierarchy**
```
├── Authentication
│   ├── Landing Page (/)
│   ├── Login/Signup (/auth)
│   └── OTP Verification (/verify)
│
├── Main Dashboard (/dashboard)
│   ├── Overview Tab
│   ├── Groups Tab
│   ├── Activity Tab
│   └── Profile Tab
│
├── Group Pages
│   ├── Group Details (/group/:id)
│   ├── Add Expense (/group/:id/add-expense)
│   ├── Settlement Page (/group/:id/settle)
│   ├── Group Settings (/group/:id/settings)
│   └── Trip Mode (/group/:id/trip)
│
├── Expense Management
│   ├── Expense Details (/expense/:id)
│   ├── Edit Expense (/expense/:id/edit)
│   └── Receipt Scanner (/scan-receipt)
│
└── User Pages
    ├── Profile Settings (/profile)
    ├── Payment History (/history)
    └── Analytics (/analytics)
```

**Tech:**
- Tesseract.js for OCR
- Image preprocessing (grayscale, contrast)
- Regex patterns for Indian receipts:
  - Total: ₹XXX / Rs. XXX / INR XXX
  - Date: DD/MM/YYYY
  - GST numbers

## 🗂️ DATABASE SCHEMA

### **MongoDB Collections**

#### **1. Users Collection**
```javascript
{
  _id: ObjectId,
  phone: "+919876543210",
  name: "Rahul Kumar",
  email: "rahul@gmail.com",
  upiIds: ["rahul@paytm", "9876543210@ybl"],
  profilePic: "url",
  createdAt: Date,
  preferences: {
    notifications: true,
    paymentReminders: true,
    weeklySummary: false
  },
  stats: {
    totalExpenses: 124560,
    groupsJoined: 8,
    fairnessScore: 92
  }
}
```

#### **2. Groups Collection**
```javascript
{
  _id: ObjectId,
  name: "Flat 301 Roommates",
  icon: "🏠",
  createdBy: userId,
  members: [
    {
      userId: ObjectId,
      role: "admin", // admin or member
      joinedAt: Date
    }
  ],
  type: "regular", // regular or trip
  tripDetails: {
    startDate: Date,
    endDate: Date,
    destination: "Goa"
  },
  createdAt: Date,
  isActive: true
}
```

#### **3. Expenses Collection**
```javascript
{
  _id: ObjectId,
  groupId: ObjectId,
  description: "Pizza Party",
  amount: 1200,
  currency: "INR",
  category: "Food",
  paidBy: userId,
  splitType: "equal", // equal, unequal, exact, shares
  splitDetails: [
    {
      userId: ObjectId,
      amount: 300,
      percentage: 25, // for unequal
      shares: 1 // for shares type
    }
  ],
  date: Date,
  receipt: {
    imageUrl: "s3-url",
    ocrData: {
      merchant: "Pizza Hut",
      items: [...],
      total: 1200
    }
  },
  isRecurring: false,
  recurringConfig: {
    frequency: "monthly", // weekly, monthly
    nextDate: Date
  },
  createdAt: Date,
  updatedAt: Date,
  createdBy: userId
}
```

#### **4. Settlements Collection**
```javascript
{
  _id: ObjectId,
  groupId: ObjectId,
  from: userId,
  to: userId,
  amount: 500,
  method: "upi", // upi, cash, other
  upiTransactionId: "string",
  notes: "Rent payment",
  settledAt: Date,
  verifiedBy: [userId1, userId2], // both parties confirm
  status: "completed" // pending, completed, disputed
}
```

#### **5. Notifications Collection**
```javascript
{
  _id: ObjectId,
  userId: ObjectId,
  type: "expense_added", // payment_received, reminder, etc
  title: "New expense added",
  message: "Amit added 'Dinner' - Your share: ₹250",
  groupId: ObjectId,
  expenseId: ObjectId,
  isRead: false,
  createdAt: Date
}
```

## 🧮 DEBT SIMPLIFICATION ALGORITHM

```javascript
/**
 * Simplifies debts in a group using graph-based algorithm
 * 
 * Input: Array of debts
 * [
 *   { from: "A", to: "B", amount: 500 },
 *   { from: "B", to: "C", amount: 300 },
 *   { from: "C", to: "A", amount: 200 }
 * ]
 * 
 * Output: Simplified debts
 * [
 *   { from: "A", to: "C", amount: 100 },
 *   { from: "B", to: "C", amount: 200 }
 * ]
 */

function simplifyDebts(debts) {
  // Step 1: Calculate net balance for each person
  const balances = {};
  
  debts.forEach(({ from, to, amount }) => {
    balances[from] = (balances[from] || 0) - amount;
    balances[to] = (balances[to] || 0) + amount;
  });
  
  // Step 2: Separate creditors and debtors
  const creditors = [];  // People who are owed money
  const debtors = [];    // People who owe money
  
  Object.entries(balances).forEach(([person, balance]) => {
    if (balance > 0) creditors.push({ person, amount: balance });
    if (balance < 0) debtors.push({ person, amount: -balance });
  });
  
  // Step 3: Match debtors with creditors
  const simplified = [];
  let i = 0, j = 0;
  
  while (i < debtors.length && j < creditors.length) {
    const debt = debtors[i];
    const credit = creditors[j];
    
    const settleAmount = Math.min(debt.amount, credit.amount);
    
    simplified.push({
      from: debt.person,
      to: credit.person,
      amount: settleAmount
    });
    
    debt.amount -= settleAmount;
    credit.amount -= settleAmount;
    
    if (debt.amount === 0) i++;
    if (credit.amount === 0) j++;
  }
  
  return simplified;
}
```

## 📊 ANALYTICS CALCULATIONS

### **Fairness Score**
```javascript
function calculateFairnessScore(userId, groupId) {
  // Get all expenses in group
  const expenses = await Expense.find({ groupId });
  
  // Calculate how much user paid vs consumed
  let totalPaid = 0;
  let totalConsumed = 0;
  
  expenses.forEach(expense => {
    if (expense.paidBy === userId) {
      totalPaid += expense.amount;
    }
    
    const userSplit = expense.splitDetails.find(s => s.userId === userId);
    if (userSplit) {
      totalConsumed += userSplit.amount;
    }
  });
  
  // Fairness = (paid / consumed) * 100
  // 100 = perfectly fair
  // >100 = paying more than share
  // <100 = paying less than share
  
  const fairness = (totalPaid / totalConsumed) * 100;
  return Math.round(fairness);
}
```
